# 代理入口安全检查（#194）

作战台 → 低干扰与隐私 → 代理入口安全检查。选择自己控制的 Clash / Mihomo YAML 文件，检查 allow-lan、bind-address、authentication、skip-auth-prefixes 和外部管理控制器的 Secret。

结果只说明配置中的风险，不检查运行状态、VPS 防火墙或公网可达性，不读取任意本机路径、不保存或回显凭据、不改变配置。选择文件会将文本提交给当前 DSH 宿主解析，远程连接时为远端宿主；建议选择脱敏配置。未发现风险不等于服务已经安全。不需要局域网共享时关闭 LAN 访问；需要共享时在可信接口使用强鉴权并核查操作系统防火墙。管理控制器优先使用回环地址。公网转发服务应单独在实际管理端核查并关闭不必要暴露。

此功能不能确认 Issue #194 的实际工作区和服务器已修复。
