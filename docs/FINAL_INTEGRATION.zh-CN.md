## 实际问题及修复

桌面使用 profile 的 link 安装，实际插件位于 `C:\Users\Kerna\.dsh\plugins\dsh-purge`，开始验收时仍为 beta.4。实际清洗台显示 GitHub 私有仓库网络/凭据读取失败；命令行上游脚本成功不能证明界面可用。
