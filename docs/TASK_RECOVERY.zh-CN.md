# 持久任务恢复与记录写入去重

## 本批解决的问题

任务状态持久化不等于可以安全重复写入：若 HTTP 证据事务已经提交，宿主却在模型收到返回之前退出，重试旧调用可能生成第二条证据。本批为已有 `redteam_http_evidence_add` 增加可选 `operation_key`，不建立第二个执行循环，不修改桌面安装。

## 协议

1. 第一次写入前确定一个稳定、不含正文或认证材料的操作键，并与 `attempt_id` 一起保留；只在收到错误后才临时生成新键无法消除旧写入的不确定性。
2. 首次调用在同一 SQLite 保存点内创建证据、尝试关联及操作回执。任一步失败全部回滚；外层事务未提交时，退出进程也不会留下其中一部分。
3. 同一尝试、相同键、相同内容再次调用，核对原证据及关联仍有效，返回原 ID 与 `replayed=true`。`method` 省略或显式 GET、其它可空字段省略或 null 使用相同默认值。采集时间与调用传输元数据不参与内容指纹；采集者 `captured_by` 参与。
4. 同键修改内容报错；原证据或关联被删除、证据内容/目标被修改时拒绝，不静默返回成功或补写。修改内容需显式选择新的记录操作，不覆盖旧操作。
5. 回执查找仅为只读核对，可在运行状态未知、已提交、已完成或已取消时返回，但仍要求原根会话和当前尝试。它不清除恢复标记，不重绑执行器，不启动新尝试，不验收交付。没有回执时的新写入仍要求 running 及有效执行绑定；未知结果先核对，再显式 reconcile。

键的范围为“演练数据库＋尝试＋键”，长度 1..200 字符，按原值精确匹配。不同尝试不会合并；省略键保持旧行为，没有键的历史写入不自动回填或合并。数据库只增加 `task_evidence_operation` 表，不重建原记录。

### 调用示例

```json
{
  "engagement": "[ENGAGEMENT]",
  "attempt_id": "[ATTEMPT_ID]",
  "operation_key": "fixture-response-v1",
  "asset_id": 1,
  "request": "GET /fixture HTTP/1.1\r\nHost: example.invalid\r\n\r\n",
  "response": "HTTP/1.1 200 OK\r\nContent-Length: 0\r\n\r\n"
}
```

首次返回 `replayed=false`；匹配的后续调用返回同一 `id` 且 `replayed=true`。这只代表本地记录存在且通过回执核对，不证明报文来自真实流量，也不代表尝试已验收。

## 独立进程恢复夹具

`test/task-process-recovery.test.mjs` 用独立 Node 子进程操作临时 RedteamStore，没有模型调用、外部目标或桌面控制。

- 24 个合成资产记录任务组成依赖链，先完成前 8 个。
- 第 9 个任务记录 method 失败；相同路线重试被拒绝。重启后显式修改路线，再开始新的尝试。
- 写入提交后立即 `process.exit(86)`，不关闭存储、不发送回执。下个进程核对原回执，无重复记录；新增写入仍被恢复门槛拦住。
- 显式 reconcile 后提交，再立即 `process.exit(87)`。下个进程读取 verifying，不能跳过恢复对账或提前启动依赖任务；对账、验收后继续完成余下任务。
- 两个全新进程重复审计完成状态和回执：24 条证据、24 条关联、24 条回执、25 次尝试（含 1 次失败），记录数量不变，路线历史和失败保留。
- 另一个场景在外层事务未提交时 `process.exit(88)`：重启后三类记录均为零；对账后用原键写入一次，重复调用不增加记录。

这些是实际进程退出与重开数据库，不是只创建一个新的内存对象；退出由夹具在固定边界主动触发，**不是操作系统强杀、磁盘故障或断电测试**。24 步很快完成，**不是长时间模型运行**，也不验证模型能自行恢复计划或正确生成稳定键。

## 官方工具注册器

`test/autonomy-official-host.test.mjs` 额外验证真实 Cordis/dsh-tools 中的插件卸载与重载：旧工具移除，重新注册后 binding 丢失，原回执可核对，新写入被阻止；显式对账后才提交及验收。停止事件仍是合成 Agent 载荷，不是桌面按钮实测。

## 尚未覆盖

外部 HTTP 请求和其它工具的副作用不在本地事务内，不能宣称 exactly-once；数据库无法观察其未回传结果。本批没有实际长时模型样本、上下文压缩/恢复、宿主跨版本升级、桌面停止按钮、并发多执行器压力、断电持久性或效果收益结论。前一批真实模型短样本不因新增确定性测试而升级证据等级。
