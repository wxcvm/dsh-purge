# 服务证据与配置核对（#191 / #197）

环境适配 → 服务证据与配置核对。选择自己管理的服务配置副本、日志文件。

- 配置漂移：将预期配置与实际取得的配置副本对比。JSON/YAML 解析后比较字段，忽略对象键顺序；数组按位置比较；TOML 等使用文本逐行位置比较，不能推断语义等价。结果只有字段路径、差异类型与数量，不含原始值。字段名也可能敏感。配置文本提交给当前 DSH 宿主解析，远程连接时为远端宿主，建议脱敏。
- 日志摘要：浏览器读取选定文件，不上传原文；统计非空行、常见英文错误/警告关键词、首末时间标记及文件修改时间。关键词可能误报或漏报，时间标记不证明日志连续、最新或服务仍在运行。
- 配置一致不证明已加载；日志存在不证明进程存活；进程存在不证明应用健康。服务状态、重启恢复及端到端功能仍须通过服务管理器和实际健康接口独立验证。
- 不启动或重启服务，不改变开机项、系统参数、防火墙或服务器配置，不保存日志与配置副本。原始 #191 / #197 的外部工作区和 VPS 尚未验收。
