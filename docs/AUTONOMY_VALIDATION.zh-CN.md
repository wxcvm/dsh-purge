# 自主执行集成验证与真实模型微型对照

日期：2026-11-13（Asia/Shanghai）。候选包含 #217—#221 的累计能力；本批不部署或合并它们。

## 分清三类证据

1. **官方工具注册器集成**：`test/autonomy-official-host.test.mjs` 在固定版本 Cordis / dsh-tools 中注册全部 Purge 工具，执行任务依赖、分类失败、知识提示、显式重试、记录归属、交付验收、停止信号及卸载清理。Agent 事件载荷是合成的，不是桌面操作。
2. **真实模型烟雾调用**：现有 codex-review 路由已返回预期文本，证明实际请求能够完成，不等同任务能力验证。
3. **真实模型＋合成记录任务**：通过桌面 headless CLI，模型真实选择工具并处理注入错误；数据、知识、故障及目标都是受控夹具，不访问业务目标。

官方注册器链路已在 `0.2.2-rc.1` 与 `0.2.2-rc.2` 各通过一次；默认 npm test 会显式跳过未配置官方 fixture 的测试。CI 的兼容性脚本会自动把此测试纳入版本矩阵，不能把跳过当作成功。

## 真实模型对照协议

- 路由：现有 codex-review；请求 provider 为 deepseek-account，model 为 deepseek-flash，reasoningEffort 为 low。服务端解析后的具体模型修订不可见，不声称固定了模型权重。
- 每组使用独立新目录、新 SQLite 和唯一归属标记；候选知识源固定为合成资料，不检索全局个人知识或 ARTEX 数据。
- 两组收到同一个合成证据交付目标，第一次写入都在工具守卫处注入 ETIMEDOUT，且注入发生在任何写入之前。
- baseline 仅暴露原有资产详情、HTTP 证据写入与查询；candidate 额外暴露持久任务工具。它是能力增量微型对照，不是历史发行包完整对照。
- 模型可见目录校验后只保留这些工具，并用单调工具守卫拒绝其它调用；16 次工具调用预算、默认每组 90 秒，默认一对，显式运行才会调用真实模型。
- 共同成功判据由退出后的数据库独立判断：资产 #1 有带指定请求行及响应状态的非空证据。候选的持久验收另列，不拿 baseline 缺少该能力判它失败。
- BENCH_DONE 仅作标记观察，不能替代产物检查，也不是语义虚报分类器。
- 报告不保存原始思考、提示词、参数、正文、模型最终全文或凭据；宿主仍可能按正常行为保存自己的 headless 会话记录。
- 入口、包清单哈希及可执行文件元数据在组间核对；若运行目录变化或不可用，停止后续组，并将已收集组标为无效。这不覆盖全部传递依赖，也不固定远端模型修订。

未正确插入插件、未完成目录隔离预检的调试运行，以及未发起模型任务的失败启动，均不纳入结果。

## 如何复跑

此脚本会真实调用已配置模型，可能产生对应账号的用量。它不会自动登录、读取令牌明文或修改 profile 配置；不要在无意消耗模型用量时运行。

```powershell
node "D:\Users\Kerna\OneDrive\文档\GitHub\dsh-purge\scripts\benchmark-autonomy-headless.mjs" `
  --exe "D:\dsh\DeepSeek Harness.exe" `
  --cli "D:\dsh\resources\app\dsh\node_modules\@deepseek-ai\dsh-desktop-host\lib\cli.js" `
  --dsh-home "C:\Users\Kerna\.dsh" `
  --profile codex-review --repeats 1 --timeout 90000
```

参数必须指向现有绝对路径，CLI 必须导出 `runDesktopCli`。当前版本要求 CLI 模块在磁盘上可读，不把 ASAR 成员路径当作普通文件。脚本在仓库 `.scratch` 下建立独占输出目录并打印报告路径，不覆盖旧报告。桌面安装更新期间应等运行文件稳定后重跑，不关闭 TLS 校验或修补宿主来强行通过。

脚本仅在组数完整、隔离与运行指纹有效、两组共同产物通过、候选额外交付验收通过时返回退出码 0；其它情况返回 1 并保留报告。这是本协议的验收，不是统计显著性或整体成功率结论。

后续需要更广的本地任务集、反复运行、严格的干预计数、上下文压缩/恢复及桌面原生停止验收；不再以新增入口或单一成功样本代替效果验证。
